# Glossar

Substance 3D Painter ist eine 3D-Anwendung, die auf vielen Techniken und technischen Stichwörtern basiert, die anfangs schwer zu verstehen sein können.\
Auf dieser Seite werden die von der Anwendung am häufigsten verwendeten Keywords zusammen mit einer kurzen Erläuterung des Konzepts dahinter aufgeführt.

| *Schlüsselwort* | *Definition* |
| --- | --- |
| **Ausrichtung** | Die Ausrichtung gibt an, wie ein Pinsel beim Malen auf das 3D-Gitter ausgerichtet wird. |
| **Alpha** | Ein Alpha ist eine Maske, die verwendet werden kann, um Details oder komplexe Formen zu zeichnen, z. B. einen Barcode oder ein Logo. |
| **Bake** | Baking (oder Backen) bezieht sich auf die Aktion der Berechnung von Informationen aus einem 3D-Mesh und das Speichern in einer Textur basierend auf den UV-Informationen eines Netzes. |
| **Bittiefe** | Die Bittiefe ist die Informationsmenge, die in einer Textur (pro Farbe) gespeichert werden kann. Je höher die Zahl, desto präziser die Informationen. Die Leistung nimmt jedoch mit hohen Zahlen ab, wenn Berechnungen durchgeführt werden. |
| **Pinsel** | Ein Pinsel ist ein Werkzeug zum Malen auf einem Netz. Ein Pinsel wird durch mehrere Parameter definiert, die sein Verhalten steuern (z. B. Größe und Deckkraft). |
| **Kamera** | Die Kamera ist das Objekt, mit dem Sie die Position und die Richtung des Betrachters in einem 3D- oder 2D-Viewport steuern können. |
| **Kanal** | Ein Kanal ist eine Textur mit einem bestimmten Verhalten. Manche Kanäle definieren die Farbe eines Materials, andere dienen der Steuerung des Verhaltens der Lichtquellen auf einer Oberfläche. |
| **Clone** | Der Klon ist ein Werkzeug, das verwendet wird, um einen Teil des Gemäldes/der Textur an einem anderen Ort zu replizieren. |
| **Inhalt/Maske** | Inhalt und Maske beziehen sich auf die beiden Haupteigenschaften einer Ebene. Der Inhalt ist das eigentliche Gemälde, das in den Kanälen gespeichert ist, die in einer Ebene enthalten sind, während die Maske verwendet wird, um den Inhalt anzuzeigen/auszublenden. Eine schwarze Maske entspricht einem unsichtbaren Inhalt. |
| **Diffusion** | Die Diffusion ist eine Möglichkeit, Informationen außerhalb der UV-Insel eines Gitters zu erzeugen. Die Methode funktioniert durch Ausbluten der letzten Pixel in der Nähe eines UV-Inselrands, wodurch verschwommene Farben erzeugt werden. |
| **Dilation/Auffüllung** | Mit derselben Vorstellung wie die Diffusion erzeugt die Dilatation Informationen außerhalb der UV-Insel, indem die Pixelfarben erweitert werden. |
| **Effekt** | Ein Effekt ist ein Element, das einer Ebene entweder im Inhalt oder in der Maske hinzugefügt werden kann. Substance 3D Painter unterstützt verschiedene Effekttypen wie z. B. Filter. |
| **Umgebung** | Bei einer Umgebung handelt es sich um ein Bild, mit dem die Beleuchtung einer Szene berechnet wird. In der Regel handelt es sich um eine HDR-Textur, die eine Vielzahl von Farbinformationen darstellt. |
| **Export** | Beim Exportieren werden abgeflachte Texturen aus dem in der Anwendung erstellten Gemälde generiert. Die beim Export erstellten Texturen können in anderen Anwendungen verwendet werden. |
| **FOV / Blickfeld** | Das FOV ist die Ausdehnung der beobachtbaren Welt durch die Kamera. |
| **Füllung** | Die Füllung ist eine Aktion (die ein Effekt oder eine Ebene sein kann), die eine Farbe, eine Textur oder sogar ein Material über das gesamte 3D-Mesh laden kann. |
| **Filter** | Ein Filter ist ein Substance-Effekt, der die vorherigen Informationen ändern kann. Ein Weichzeichnungsfilter mildert beispielsweise ein vorheriges Bild ab. Filter können auch komplexer sein und ein komplettes Material verändern. |
| **Filtern** | Die Filterung bezieht sich auf die Art und Weise, wie Texturen in einem 3D-Viewport angezeigt werden. Am weitesten verbreitet sind die nächstgelegenen Pixel (Pixel werden unverändert gelesen, wodurch ein Bild blockartig in der Nähe erscheint) und die bilinearen Pixel (Pixel werden interpoliert, wodurch ein Bild unscharf in der Nähe erscheint). |
| **GPU** | Die GPU (Graphic Processing Unit) ist der Teil eines Computers, der eine schnelle Berechnung für die Erzeugung von Bildern durchführt. |
| **Generator** | Ein Generator ist eine Substance, die neue Informationen/Bilder erzeugt, die in der Regel auf zusätzlichen Texturen basieren. Einige Maskengeneratoren verwenden z. B. Texturen im Hintergrund, um komplexe Masken zu erstellen. |
| **Histogramm** | Ein Histogramm ist eine grafische Darstellung der Verteilung von Farbwerten. Es dient zur Visualisierung des Farbausgleichs zwischen Schatten, Mitteltönen und Lichtern innerhalb eines Bildes. |
| **Ira** | Iray ist ein von NVIDIA erstellter Pfad-Tracer-Renderer, mit dem eine realistische Beleuchtung über das 3D-Mesh projiziert wird. Da es sich um einen erweiterten Renderer handelt, ist es für die Erstellung schöner Bilder gedacht und nicht für Echtzeitarbeiten. |
| **Jitter** | Der Jitter ist eine Eigenschaft des Pinsels, um beim Malen ein zufälliges Verhalten zu erzeugen. |
| **Ebene** | Eine Ebene ist ein Element, das mehrere Kanäle mit zusätzlichen Eigenschaften wie Füllmethode und Deckkraft enthält. |
| **Ebenenstapel** | Ein Ebenenstapel ist ein Ort, an dem Ebenen verwaltet und organisiert werden können. Ebenen werden von unten nach oben organisiert. Zuerst wird die untere Ebene gezeichnet, dann werden die einzelnen Ebenen übereinander angeordnet. |
| **Faule Maus** | Die träge Maus ist ein Verhalten des Pinselwerkzeugs. Es verlangsamt den Pinselpfad, um die Präzision beim Malen zu erhöhen, und erzeugt eine Verzögerung/einen Versatz zwischen dem Mauszeiger und dem eigentlichen Malen. |
| **Ebene** | Ein Level ist ein Effekt, mit dem Sie einen Bereich oder Farb-/Graustufeninformationen über ein Histogramm steuern können. Sie kann zum Beispiel verwendet werden, um Farben umzukehren oder Farben abzudunkeln/aufzuhellen. |
| **Protokoll** | Ein Protokoll ist eine Textdatei, in die Informationen aus der Software geschrieben werden, die sich normalerweise auf den Computer beziehen, auf dem die Anwendung ausgeführt wird. |
| **Niedriges/hohes Polygitter** | Ein niedriges und ein hohes Polygitter sind beide 3D-Gitter, eines mit einer niedrigen Dichte an Polygonen, das andere mit einer höheren Polyanzahlmenge (oft 100-mal größer). Normalerweise werden die Informationen mit hohem Mesh auf das niedrige Mesh reduziert. |
| **Material** | Ein Material definiert die Eigenschaften für ein bestimmtes Thema. Bei 3D-Meshs wird das Material auch zum Definieren von Gruppen von Polygonflächen verwendet. |
| **Mesh** | Ein Gitter ist ein 3D-Objekt, das durch mehrere Informationen definiert wird. In Substance 3D Painter wird ein Gitter durch Polygone (in der Regel Dreiecke) definiert. Ein Gitter kann in einer 3D-Modellierungsanwendung wie **Blender** oder **Autodesk Maya** erstellt werden. |
| **Mesh-Map** | Eine Gittermaske ist eine aus einem Gitter aufgebaute Maske, die relativ zum Gitter Informationen enthält. Es kann sich beispielsweise um eine Positionsinformation oder um eine Information der Verdeckung handeln. |
| **MIP-Map** | Eine MIP-Map ist eine vorberechnete Textur, die in der Regel als Bildsequenz jedes Mal mit einer niedrigeren Auflösung als die ursprüngliche Textur vorliegt. |
| **Modus** | Ein Modus bezieht sich auf das Setup der Benutzeroberfläche, die Zugriff auf einen bestimmten Satz von Werkzeugen und Steuerelementen je nach Modus bietet. |
| **Rauschen** | Ein Rauschen ist ein prozedurales und zufälliges Bild, das in der Regel organische Formen und Farb-/Graustufenwerte darstellt. |
| **Normal** | Eine Normale ist eine spezielle Textur, die das Verhalten eines Lichts auf der Oberfläche eines 3D-Gitters verformt, um Details zu simulieren, die in der Geometrie nicht vorhanden sind. |
| **OpenGL / DirectX** | OpenGL und DirectX sind beide eine API (Application Programming Interface) zum Rendern von 2D- und 3D-Informationen. Sie definieren auch die Normalen-Map-Format. |
| **Orthographisch** | Eine orthographische Projektion ist ein Mittel zur Darstellung dreidimensionaler Objekte in zwei Dimensionen, in denen alle Projektionslinien orthogonal zur Projektionsebene sind. |
| **PBR / PBS** | Physikalisch basiertes Rendering (PBR) oder Physikalisch basierte Schattierung (PBS) ist ein Modell in der Computergrafik, das versucht, Grafiken auf eine Weise zu rendern, die den Lichtfluss in der realen Welt genauer modelliert. |
| **Packing** | Beim Verpacken werden mehrere Bilder in einer Textur gespeichert. Da Texturen aus getrennten Kanälen für Rot, Grün und Blau bestehen, können sie unterschiedliche Informationen speichern, die unabhängig in einer anderen Anwendung gelesen werden können. |
| **Partikel** | Partikel sind eine Art Werkzeug, mit dem sich Pinselstriche auf Basis physikalischer Eigenschaften oder anderer komplexer Verhaltensweisen erzeugen lassen. |
| **Perspektive** | Die Perspektive ist eine ungefähre Darstellung eines Objekts oder einer Szene, die vom menschlichen Auge auf einer flachen Oberfläche (wie ein Bildschirm) gesehen wird. Es ist eine Simulation von Tiefe und Maßstab. |
| **Pixel / Texel** | Ein Pixel ist ein Punkt in einem Bild, es ist das kleinstmögliche Element, das Farbinformationen enthält. Je größer die Auflösung, desto mehr Pixel sind verfügbar, was eine bessere Definition und mehr Details ermöglicht. Texel sind Pixel innerhalb einer Textur. |
| **Plug-In** | Plugins sind Programmierfunktionen (oft über Scripting ausgedrückt), die der Software hinzugefügt werden können, um die Möglichkeiten der Anwendung zu erweitern. |
| **Nachbearbeitung** | Ein Nachbearbeitungsprozess ist ein visueller Effekt, der auf den Bildschirm angewendet wird, sobald das 3D-Bild gerendert wurde, häufig um ein spezielles Verhalten wie Farbkorrektur oder Blüte zu simulieren. |
| **Procedural** | &quot;Prozedurale&quot; ist ein Begriff zum Beschreiben von Prozessen, die von einem Computer auf der Grundlage einer Reihe von Parametern generiert werden. Es kann sich einfach um mathematische Ergebnisse wie Zahlen oder komplexe Bilder handeln. |
| **Projektion** | Eine Projektion ist die Aktion, bei der ein Bild/Objekt aus einem bestimmten Blickwinkel (z. B. der Kamera) auf die Oberfläche des 3D-Gitters angewendet wird. |
| **Auflösung (Leistung von 2)** | Die Auflösung definiert die Größe einer Textur auf ihrer X- und Y-Achse (oder Breite und Height). Oft in einer Leistung von 2 Skala (2, 4, 8, 16... 512, 1024, 2048...) da es für Berechnungen auf einer GPU optimiert ist. |
| **Skripterstellung** | Scripting ist der Vorgang oder die Verwendung eines bestimmten Befehls über ein textbasiertes Dateiformat, um bestimmte Verhalten auszuführen. |
| **Shader** | Ein Shader definiert das Verhalten eines Materials, wenn es Beleuchtungsinformationen erhält. Bei manchen Shadern kann es sich um eine simple Shader-Schattierung (wie eine Zehn-Zehn-Schattierung) oder eine komplexere Shader-Absorption handeln (wie bei der Hautoberfläche, die eine helle Oberfläche simuliert). |
| **Shelf** | Eine Ablage ist die Stelle in der Anwendung, an der Ressourcen unterschiedlicher Art organisiert sind. Es kann von einfachen Bildern zu komplexeren Werkzeugen führen. |
| **Smart Mask** | Intelligente Masken verhalten sich wie intelligente Materialien, aber anstatt Ebenen zu sein, sind sie Effekte, die so definiert sind, dass sie Masken nur basierend auf dem aktuellen 3D-Mesh generieren. |
| **Smart Material** | Intelligentes Material ist eine Ebenengruppe, die als eine Datei gespeichert wird. Smart-Materialien lassen sich an jedes Projekt in Substance 3D Painter anpassen. So lassen sich Materialien erstellen, die sich je nach aktuellem 3D-Mesh ändern. |
| **Verwischen** | Der Wischfinger ist ein Werkzeug zum Ausbluten, Verteilen oder Mischen von Farben. Das Werkzeug wird häufig zum Weichzeichnen von Pixeln verwendet. |
| **Schablone** | Eine Schablone ist ein Bild, das am Bildschirm ausgerichtet und mit einer Kameraprojektion zum Malen auf dem 3D-Mesh verwendet wird. |
| **Substance** | Ein Substance ist ein Dateiformat, mit dem Sie Texturen anhand von Parametern (einschließlich prozeduraler Berechnungen) generieren können. Diese Parameter können geändert werden, um Variationen zu erzeugen. |
| **Symmetrie** | Die Symmetrie ist eine Option eines Werkzeugs, das es ermöglicht, an zwei Stellen gleichzeitig im Spiegel zu malen. |
| **Vorlage** | Eine Vorlage ist ein Satz vordefinierter Optionen, die beim Erstellen eines neuen Projekts verwendet werden. Sie kann beispielsweise die Standardauflösung oder die Standardeinstellung für die Backeinstellungen definieren. |
| **Texel-Verhältnis** | Das Texelverhältnis ist die Regel, mit der die Größe einer UV-Insel (2D) und die damit verbundene Geometrie des 3D-Gitters verglichen werden. Ein gutes Texelverhältnis bedeutet eine gleichmäßige Entfaltung der Geometrie in 2D. Dies ist wichtig, um den Look und die Qualität des Bildes/der Texturierung auf dem 3D-Mesh konsistent zu halten. |
| **Struktur** | Eine Textur ist eine Datei, die Pixel in zwei Dimensionen enthält, die durch eine Auflösung definiert sind. Die Pixel können grau oder farbig dargestellt werden. Beim Einfärben können die Pixel über Transparenzinformationen verfügen (sofern diese vom Dateiformat unterstützt werden). |
| **Textursatz** | In Substance 3D Painter stellt ein Texturensatz einen Teil eines Gitters dar, auf dem bestimmte UVs gemalt werden. Der Textursatz wird für jedes eindeutige Material erstellt, das beim Importieren eines 3D-Gitters erkannt wird. |
| **Auffüllen** | Tilling ist die Wiederholung einer Textur, bei der Nähte nicht sichtbar sind an den Rändern, es ist dazu gedacht, eine unendliche Ebene zu simulieren. Beispiel : Gras oder Bürgersteige. |
| **Tool** | Ein Werkzeug bezieht sich auf eine Aktion, die eine Interaktion mit dem 3D-Mesh ermöglicht, häufig zum Malen oder Anwenden von Effekten. |
| **Symbolleiste** | Die Symbolleiste ist der Speicherort, an dem alle Symbolverknüpfungen zu den Werkzeugen verfügbar sind. |
| **UDIM** | UDIM ist eine Möglichkeit, die UVs eines 3D-Gitters über mehrere Bereiche aufzuteilen, um die allgemeine Texturauflösung zu erhöhen. |
| **UV** | UV sind Informationen, die in einem 3D-Mesh definiert sind und angeben, wie es zu einer flachen Form ausgeklappt werden kann. Diese Informationen werden verwendet, um eine Textur auf ein 3D-Mesh zu projizieren. In Substance 3D Painter können Sie nur im Bereich von 0 bis 1 malen, der der Größe einer Textur entspricht. Andere Bereiche werden nur über das UDIM-System unterstützt. |
| **VRam** | Der VRam ist der Speicher der GPU (Grafikkarte), die zum Speichern von Informationen und Texturen bei Berechnungen verwendet wird. Je mehr VR, desto besser für die Arbeit mit Substance 3D Painter. |
| **Viewport** | Der Viewport ist der Ort, an dem die 3D- oder 2D-Szene auf dem Bildschirm angezeigt wird. Dort können Sie zudem durch Steuerung der Kamera mit den Werkzeugen und dem 3D-Mesh interagieren. |
