# Baking-Modus

Der **Backmodus** bietet Zugriff auf alle Tools und Parameter, die Sie zum Erstellen großartiger Backs mit hoher Qualität benötigen.

Um auf den **Backmodus** zuzugreifen, klicken Sie auf die (gebackene) Croissant-Schaltfläche oben rechts im Viewport. Alternativ können Sie den [Tastaturbefehl &#x200B;](../interface/settings/shortcuts.md)**F8** verwenden oder **Modus > Gitterzuordnungen backen** auswählen.

![](../assets/baking/mode_select_buttons.png)

Im Backmodus können Sie das UI-Layout ändern und verschiedene Bedienfelder speziell zum Backen von Gitterzuordnungen verfügbar machen.

## Benutzeroberfläche

Die Backmodusschnittstelle ist standardmäßig zwischen dem [**Viewport**](../interface/viewport/viewport.md) und dem Fensterbereich aufgeteilt.

### Viewport

Der [**Viewport**](../interface/viewport/viewport.md) verhält sich genauso wie im **Malmodus**. Sie können mit denselben Steuerelementen navigieren und mithilfe der Dropdown-Liste **Kanal** ändern, welche Kanäle angezeigt werden.

Der Viewport für den **Backing-Modus** unterscheidet sich vom **Malmodus** in zweierlei Hinsicht:

* Links oben im Viewport befindet sich das Fenster [**Einstellungen für die Backvisualisierung**](baking-visualization-settings.md).
* Am unteren Rand des Ansichtsfensters finden Sie Schaltflächen zum **Bake** der aktuell ausgewählten Gitterzuordnungen oder zum **Malmodus**.

### Backmodus - Fenster

Im Backmodus stehen vier Bedienfelder zur Verfügung:

* [**Gitterzuordnungs-Bäcker**](../interface/baking-panels/mesh-map-bakers.md): Wählen Sie aus, welche Gitterzuordnungen als Stapel vorliegen.
* [**Allgemeine Einstellungen**](../interface/baking-panels/common-mesh-map-settings.md): Passen Sie die Backeinstellungen für alle Gitterzuordnungen an.
* [**Einstellungsfenster für Mesh-Map**](../interface/baking-panels/mesh-map-settings.md): Passen Sie die Backeinstellungen für die ausgewählte Gittermaske an.
* [**Sicherungsprotokoll**](../interface/baking-panels/baking-log.md): Zeigen Sie die Ergebnisse von Backs an und diagnostizieren Sie Probleme.

>[!NOTE]
>
> Eine vollständige Liste der Optionen, die in den **allgemeinen Einstellungen** und **Fenstern mit Einstellungen für Mesh-Maps** verfügbar sind, finden Sie unter [**Einstellungen für Mesh-Maps**](mesh-map-settings.md).
