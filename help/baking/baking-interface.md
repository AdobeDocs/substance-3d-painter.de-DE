# Baking-Modus

Der **Baking-Modus** bietet Zugriff auf alle Tools und Parameter, die Sie zum Erstellen großartiger, qualitativ hochwertiger Baking führte benötigen.

Um auf den **Baking-Modus** zuzugreifen, klicken Sie auf die (Baking geführt) Croissant-Schaltfläche oben rechts im Viewport. Alternativ können Sie den [Tastatur-Tastaturbefehl ](../interface/settings/shortcuts.md)**F8** verwenden oder den **Modus > Mesh-Map-Baking** auswählen.

![](../assets/baking/mode_select_buttons.png)

Im Baking-Modus ändern Sie das UI-Layout und stellen verschiedene Bedienfelder speziell für Baking führend Mesh-Map zur Verfügung.

## Benutzeroberfläche

Die Baking Mode-Oberfläche ist standardmäßig zwischen dem [**Viewport**](../interface/viewport/viewport.md) und dem Bedienfeldbereich aufgeteilt.

### Viewport

Der [**Viewport**](../interface/viewport/viewport.md) verhält sich genauso wie im **Malmodus**. Sie können mit denselben Steuerelementen navigieren und mithilfe der Dropdown-Liste **Kanal** ändern, welche Kanäle angezeigt werden.

Der Viewport &quot;**Malmodus&quot; &quot;**&quot; unterscheidet sich von &quot;**Baking&quot;-Modus &quot;**&quot; auf zwei Arten:

* Oben links im Viewport befindet sich das Einstellungsbedienfeld für die [**Baking-Visualisierung**](baking-visualization-settings.md).
* Am unteren Rand des Viewports finden Sie Schaltflächen zum **Baking** der aktuell ausgewählten Mesh-Map oder zum **Malmodus**.

### Baking-Modus Bedienfelder

Es gibt 4 Bedienfelder, die nur im Baking-Modus verfügbar sind:

* [**Mesh-Map Baker**](../interface/baking-panels/mesh-map-bakers.md): Wählen Sie aus, welche Mesh-Map Baking geführt werden.
* [**Allgemeine Einstellungen**](../interface/baking-panels/common-mesh-map-settings.md): Passen Sie die Baking-Einstellungen in allen Mesh-Map an.
* [**Einstellungsbedienfeld für Mesh-Map**](../interface/baking-panels/mesh-map-settings.md): Passen Sie die Baking-Einstellungen für den ausgewählten Mesh-Map an.
* [**Protokoll**](../interface/baking-panels/baking-log.md) wird Baking geführt: Zeigen Sie die Ergebnisse von Baking führte an und diagnostizieren Sie Probleme.

>[!NOTE]
>
> Eine vollständige Liste der Optionen, die in den **Einstellungsfenstern für allgemeine** und **Mesh-Map verfügbar sind, finden Sie unter[** Mesh-Map-Einstellungen **](mesh-map-settings.md).**.
