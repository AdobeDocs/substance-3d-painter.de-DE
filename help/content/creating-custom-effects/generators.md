# Generatoren

Ein Generator verhält sich wie ein Filter, der Unterschied ist, dass es keinen anderen Eingabeknoten als die zusätzlichen Karten gibt. Wenn Sie einen Kanal aus dem Textursatz lesen müssen, dann möchten Sie einen Filter erstellen.
