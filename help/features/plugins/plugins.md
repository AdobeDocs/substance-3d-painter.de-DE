# Plug-ins

Substance 3D Painter verfügt über eine spezielle Scripting-API, mit der Sie benutzerdefinierte Plug-ins erstellen können, um benutzerdefinierte Funktionen und Verhalten hinzuzufügen.\
Die Plugins sind in Javascript geschrieben und können mit der QML-Sprache kombiniert werden, um eine benutzerdefinierte Schnittstelle innerhalb der Anwendung zu erstellen. Weitere Informationen zu den in der API verfügbaren Funktionen finden Sie in der Skriptdokumentation (verfügbar im Hilfemenü der Anwendung).

## Standard-Plug-ins

Substance 3D Painter verfügt über zwei Standard-Plug-ins, die unterschiedliche Versionen anzeigen.

* [Automatisches Speichern](autosave.md)
* [Resources Updater](resources-updater.md)
