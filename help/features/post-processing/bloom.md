# Bloom

![](../../assets/v12_post_bloom.jpg)

Erzeugt ein weiches Leuchten um helle Bereiche der Szene. Simuliert, wie helle Streuungen in einer hellen Aura entstehen.

| <b>Parameter</b> | <b>Beschreibung</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Betrag</b> | Steuert die Intensität des Blüteneffekts. Höhere Werte erzeugen einen kräftigeren Schein um helle Bereiche herum. |
| <b>Schwellenwert</b> | Legt die minimale Helligkeitsstufe fest, die zum Auslösen von Blüten erforderlich ist. Nur Pixel, die heller als dieser Wert sind, leuchten. Ein Schwellenwert von 1,0 bedeutet, dass nur Pixel blühen, die heller als das Bildschirmweiß sind. |
| <b>Abfall</b> | Bestimmt, wie weit sich die Blüte von hellen Bereichen ausbreitet. Niedrigere Werte erzeugen einen kompakteren Schein, während höhere Werte den Effekt über einen größeren Bereich verteilen. |
