# Filmkörnung

![](../../assets/v12_post_grain.jpg)

Fügt dem Rauschen ein Filmkörnung-Muster hinzu, das die organische Textur eines analogen fotografischen Films simuliert.

| <b>Parameter</b> | <b>Beschreibung</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Betrag</b> | Steuert die Sichtbarkeit und Intensität der Körnung. Höhere Werte führen zu auffälligeren, auffälligeren Rauschen. |
| <b>Radius</b> | Legt die Größe der einzelnen Körnungspixel in Partikeln fest. Kleinere Werte erzeugen eine feinere, feinere Körnung. Größere Werte erzeugen eine gröbere, sichtbarere Textur. |
| <b>Typ</b> | Legt fest, ob das Rauschen monochromatisch oder farbig ist. |

>[!NOTE]
>
> Die durch diesen Effekt generierte Rauschen wird bei jeder Aktualisierung des Viewports neu generiert. Dies ist der Grund, warum die Rauschen aktualisiert werden kann, wenn Schatten erzeugt werden oder wenn die Kamera gedreht wird.
