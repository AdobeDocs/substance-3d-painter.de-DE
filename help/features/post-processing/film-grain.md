# Filmkörnung

![](../../assets/v12_post_grain.jpg)

Fügt dem Bild ein Filmkörnung-Rauschmuster hinzu, das die organische Textur eines analogen fotografischen Films simuliert.

| <b>Parameter</b> | <b>Beschreibung</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Betrag</b> | Steuert die Sichtbarkeit und Intensität der Körnung. Höhere Werte erzeugen auffälligere, auffälligere Geräusche. |
| <b>Radius</b> | Legt die Größe der einzelnen Kornteilchen in Pixel fest. Kleinere Werte erzeugen eine feinere, feinere Körnung. Bei größeren Werten entsteht eine gröbere, sichtbarere Textur. |
| <b>Typ</b> | Legt fest, ob das Rauschen monochromatisch oder farbig ist. |

>[!NOTE]
>
> Das durch diesen Effekt erzeugte Rauschen wird bei jeder Aktualisierung des Viewports neu generiert. Aus diesem Grund kann das Rauschen bei der Erzeugung von Schatten oder beim Drehen der Kamera aktualisiert werden.
