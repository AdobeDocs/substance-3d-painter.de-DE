# Schärfen

![](../../assets/v12_post_sharpen.jpg)

Verbessert die Kanten und feinen Details des Bildes, um die wahrgenommene Schärfe zu erhöhen.

| <b>Parameter</b> | <b>Beschreibung</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Betrag</b> | Steuert die Intensität des Scharfzeichnungseffekts. Höhere Werte erhöhen den Kantenkontrast drastischer. |
| <b>Durchmesser</b> | Legt die Größe des Scharfzeichnungseffekts in Pixel fest. Kleinere Werte schärfen feine Details. Größere Werte wirken sich auf breitere Kanten aus und können einen ausgeprägteren Effekt erzeugen. |
