# Senden an

![Bannerbild](../assets/sendto_banner.jpg)

<b>Senden an</b> sind Aktionen zum einfachen Exportieren und Importieren von Ressourcen aus einem Projekt in eine andere Anwendung, sodass dies nicht manuell erfolgen muss. Mit &quot;Senden an&quot; können Sie das 3D-Modell und seine Texturen in eine andere Rendering-Anwendung exportieren oder Substance-Materialien von Substance 3D Designer erhalten.

Die Aktionen &quot;Senden an&quot; sind über das Menü <b>Datei > Senden</b> an verfügbar.

Die derzeit unterstützten <b>Senden an</b> sind:

* An <b>Photoshop</b> senden
* An <b>Substance 3D Stager</b> senden
* An <b>After Effects</b> senden

Painter kann auch Ressourcen von anderen Anwendungen erhalten, z. B.:

* <b>Substance 3D Designer</b>
* <b>Substance 3D Sampler</b>

Weitere Informationen zum Empfangen von Ressourcen finden Sie auf der [Seite der dedizierten Dokumentation](../content/importing-assets/receiving-assets-from-other-substance-3d-applications.md).

>[!NOTE]
>
> Einige der Arbeitsabläufe von &quot;Senden an&quot; sind nur in der Adobe-Version von Painter verfügbar, da für die Creative Cloud Desktop-Software technische Abhängigkeiten bestehen.
> 
> Außerdem sind einige Aktionen im Menü Senden an möglicherweise nicht verfügbar, wenn die erforderliche Software nicht installiert ist.
