# Farbe

Dieser Effekt ermöglicht es, andere Effekte zu übermalen. Es verhält sich wie eine Ebene, was bedeutet, dass Sie Zugriff auf die verschiedenen Füllmethoden und eine Deckkraftsteuerung haben.
