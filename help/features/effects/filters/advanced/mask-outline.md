## Beschreibung

Der Filter &quot;Maskenkontur&quot; erstellt einen Umriss von den Kanten einer Maske.

Sie wird auf einer Maskenebene oder innerhalb einer Textur (Schwarzweißausgabe) verwendet, um eine Innen-, Außen- oder Doppelkontur um eine maskierte Form zu generieren.

<a name="parameters"></a>

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Maskenposition:</b> | Legen Sie fest, ob die Kontur außerhalb, innerhalb oder auf beiden Seiten der Maskenkante erscheint. |
| <b>Von Schwarz starten:</b> | Stellt ein, ob die Umrisslinie schwarz beginnt. Dies fungiert effektiv als eine Art Umkehrschalter. |
| <b>Schwellenwert:</b> | Passen Sie den Schwellenwert für die Erkennung der Maskenkante an. |
| <b>Breite:</b> | Passen Sie die Breite der Kontur an. |
| <b>Weichzeichnen:</b> | Passen Sie den Weichzeichner an, der auf die Kontur angewendet wird. |
| <b>Kurvenform:</b> | Passen Sie die Form des Konturabfalls an. |
