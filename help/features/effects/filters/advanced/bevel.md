## Beschreibung

Mit dem Filter &quot;Abgeflachte Kante&quot; können Sie Graustufenformen und -masken eine abgeflachte Kante hinzufügen.

Sie wird auf einer Maskenebene oder innerhalb einer Textur (Schwarzweißausgabe) verwendet, um ein abgeflachtes Relief entlang der Kanten einer Form zu erstellen.

<a name="parameters"></a>

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Abgeflachte Kante - Umbruch:</b> | Aktiviere/deaktiviere die Umhüllung, sodass die abgeflachte Kante horizontal und vertikal angeordnet ist. |
| <b>Entfernung:</b> | Passen Sie die Größe der abgeflachten Kante an. |
| <b>Eckentyp:</b> | Wählen Sie aus, ob abgeflachte Ecken abgerundet oder angular sind. |
| <b>Glättung:</b> | Passen Sie den Grad der Glättung an, der auf die abgeflachte Kante angewendet wird. Ohne Glättung können gekrümmte Schrägen aufgrund von Aliasing entlang der Kurve sichtbare Streifen aufweisen. |
| <b>Weichzeichnungsmodus:</b> | Wählen Sie aus, ob für die abgeflachte Kante eine einheitliche oder nicht einheitliche Weichzeichnung verwendet wird. Bei der Option &quot;Uneinheitlicher Weichzeichner&quot; wird der Unschärfe-Effekt auf die abgeflachten Bereiche fokussiert, was hilfreich sein kann, um Details beizubehalten, aber eine gleichmäßige Weichzeichnung ist konsistenter. |
