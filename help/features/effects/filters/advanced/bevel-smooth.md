## Beschreibung

Der Maskenfilter zeichnet einen Verlauf von den Rändern einer Weiche Abschrägung nach außen, nach innen oder in beiden Richtungen.

Sie wird auf einer Maskenebene oder innerhalb einer Textur (Schwarzweißausgabe) verwendet, um einen glatten, abgeflachten Verlauf von den Kanten einer Maske aus zu erzeugen.

## Eingaben

| Eingabename | Beschreibung |
| --- | --- |
| <b>Abstands-Map:</b> Graustufen | Verwenden einer benutzerdefinierten Textur oder eines Ankerpunkts. |

<a name="parameters"></a>

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Richtung:</b> | Wählen Sie die Seite des Maskenrahmens aus, die erweitert werden soll. |
| <b>Entfernung:</b> | Passen Sie den Abstand der Ausdehnung &quot;Abgeflachte Kante&quot; an. |
| <b>Glättung:</b> | Passen Sie die Intensität der auf die Maske angewendeten Glättung an. |
| <b>Kurvenversatz:</b> | Passen Sie die Maskenränder nach innen oder außen an. |
| <b>Kurvenform:</b> | Wählen Sie aus, ob die abgeflachte Steigung eine gequetschte oder abgerundete Kurve verwendet. |
| <b>Maskenschwellenwert:</b> | Passen Sie den Wert an, mit dem die Ränder der Maske in der Eingabe erkannt werden. |
| <b>Abstands-Map-Multiplikator:</b> | Passen Sie die Auswirkung des Abstands-Map auf die maximale Entfernung an. |
| <b>Abgeflachte Kante - Umbruch:</b> | Stellt ein, ob die abgeflachte Kante horizontal und vertikal kachelt. |
