## Beschreibung

Der Filter &quot;Verlaufskurve&quot; ordnet Werte über eine anpassbare Verlaufskurve neu zu.

Sie wird auf einer Maskenebene oder innerhalb einer Textur (Schwarzweißausgabe) verwendet, um Graustufenwerte mit voreingestellten Kurvenformen neu zuzuordnen.

<a name="parameters"></a>

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Vorgabe:</b> | Wählen Sie die Kurvenvorgabe aus. |
| <b>Umkehren:</b> | Kehrt die Umkehrung des Ergebnisses um. |
| <b>Saldo:</b> | Passen Sie die Balance des Ergebnisses zwischen Schwarz und Weiß an, ähnlich wie bei einer Helligkeitsanpassung. |
| <b>Kontrast:</b> | Passen Sie den Kontrast oder den Tonfall des Ergebnisses an. |
