## Beschreibung

Der MatFinish Rough-Filter ist Teil einer Metal-Finish-Sammlung und wird verwendet, um einen Rohmetalleffekt zu erzeugen.

Es wird auf einer Füllebene verwendet. Passe Füllebene, Rauheit, metallic und andere Eigenschaften der Basisoberfläche an. Gib den gewünschten Filter für die abschließende Oberflächenbehandlung ein.

<a name="parameters"></a>

## Eingaben

| Eingabename | Beschreibung |
| --- | --- |
| <b>Benutzerdefinierter Schmutz:</b> Graustufen | Verwenden Sie eine benutzerdefinierte Schmutz-Textur oder einen Ankerpunkt. |
| <b>Position:</b> Farbe | Verwenden Sie die Baking geführt Positionszuordnung. |
| <b>Welt-Raum-Normale:</b> Farbe | Verwenden Sie die Baking geführt Welt-Raum-Normale-Map. |

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Seed:</b> | Weisen Sie einen zufälligen Wert zu, um eine andere Variation zu erstellen, ohne die Gesamteinstellungen zu ändern. |
| <b>Skalierung:</b> | Passen Sie die Gesamtskala der Oberfläche an. |
| <b>Schmutz skalieren:</b> | Passen Sie die Skalierung des Schmutzes an. |
| <b>Pinselintensität:</b> | Passen Sie die Intensität des Pinseleffekts an. |
| <b>Verzerrung:</b> | Passen Sie die Stärke der Verformung an, die auf das Pinselwerkzeug angewendet wird. |
| <b>Benutzerdefinierte Flake verwenden:</b> | Verwenden der benutzerdefinierten Flake-Eingabe umschalten. |
| <b>Triplanare Zuordnung:</b> | Dreidimensionale Zuordnung ein/aus. |
| <b>Benutzerdefinierten Schmutz verwenden:</b> | Verwendung einer benutzerdefinierten Schmutz-Textur umschalten. |
