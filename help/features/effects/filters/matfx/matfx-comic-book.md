## Beschreibung

Der MatFX Comic Book-Filter stilisiert Materials im Comic-Book-inspirierten Look.

Es wird auf Grafikebenen verwendet, um einen grafischen, illustrierten Rendering-Stil mit vereinfachter Schattierung und einer fetten visuellen Textur zu erstellen.

## Eingaben

| Eingabename | Beschreibung |
| --- | --- |
| <b>Ambient occlusion:</b> Graustufen | Verwenden Sie die Baking geführt ambient occlusion-Map. |
| <b>Krümmung:</b> Graustufen | Verwenden Sie die Baking geführt Krümmungs-Map. |

<a name="parameters"></a>

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Eingabetyp:</b> | Wählen Sie den vom Effekt verwendeten Eingabetyp aus. |
| <b>Eingabekontrast:</b> | Passen Sie den Kontrast der Eingabe an. |
| <b>Luminanzeingabe:</b> | Passen Sie die Luminanz der Eingabe an. |
| <b>Farbintensität:</b> | Passen Sie die Intensität der Farbbehandlung an. |
| <b>Rahmendeckkraft:</b> | Passen Sie die Deckkraft der Rahmen an. |
| <b>Rahmentoleranz:</b> | Passen Sie die Toleranz für die Randerkennung an. |
| <b>Border-Smoothness:</b> | Passen Sie die Smoothness der Rahmen an. |
| <b>Malen-Intensität:</b> | Passen Sie die Intensität des Malen-Effekts an. |
| <b>Verkrümmen:</b> | Verzerrungseffekte korrigieren. |
| <b>Schärfe:</b> | Passen Sie die Schärfe des Ergebnisses an. |
| <b>Ausgabekontrast:</b> | Passen Sie den Kontrast der Ausgabe an. |
| <b>Ausgabeluminanz:</b> | Passen Sie die Luminanz der Ausgabe an. |
