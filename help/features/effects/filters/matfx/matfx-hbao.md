## Beschreibung

Der MatFX HBAO-Filter erzeugt horizon-basierte ambient occlusion aus Height-Informationen.

Sie wird auf Maskenebenen oder -masken verwendet, um Tiefe hinzuzufügen und Texturen zu kontaktieren, die auf den Quellkanal- oder Height-Informationen basieren.

<a name="parameters"></a>

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Weichzeichnungsintensität:</b> | Passen Sie die Weichzeichnungsintensität des Ergebnisses an. |
| <b>Weichzeichnungsumbruch:</b> | Weichzeichnungsumbruch ein/aus. Wenn diese Option aktiviert ist, nimmt der Effekt Pixel von der gegenüberliegenden Seite der Textur auf. |
| <b>Kanalquelle:</b> | Wählen Sie die Kanalquelle aus, die zum Generieren der Verdeckung verwendet wird. |
| <b>Welteinheiten verwenden:</b> | Nutzung von Weltraumeinheiten umschalten. |
| <b>Height-Tiefe:</b> | Passen Sie die wahrgenommene Tiefe des Heights an. |
| <b>Radius:</b> | Passen Sie den Sampling-Radius des Effekts &quot;Verdeckung&quot; an. |
| <b>Intensität:</b> | Passen Sie die Stärke der Verdeckung an. |
| <b>Relief-Saldo:</b> | Passen Sie den Saldo des Reliefs an. |
