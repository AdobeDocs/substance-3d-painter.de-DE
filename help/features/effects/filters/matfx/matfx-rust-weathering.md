## Beschreibung

Der MatFX Rost Verwitterung-Filter erstellt Rost-Aufbau und Verwitterung über ein Material.

Es wird auf Texturen oder Material-Stapeln verwendet, um Korrosion, Tropfen und gealterte Verwitterung hinzuzufügen.

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Weichzeichnungsintensität:</b> | Passt die Stärke des Unschärfe-Effekts an. |
| <b>Weichzeichnungsumbruch:</b> | Schaltet den Weichzeichnungseffekt ein bzw. aus. Wenn die Weichzeichnungsumhüllung aktiviert ist, werden Pixel von der gegenüberliegenden Seite der Textur aufgenommen. |
| <b>Rost-Verteilung:</b> | Anpassen der Rost-Verteilung |
| <b>Spread-Smoothness:</b> | Anpassen der sich ausbreitenden Smoothness. |
| <b>Varnish Damage Scale:</b> | Passen Sie die Schadenskala des Lackes an. |
| <b>Tropfintensität:</b> | Tropfenintensität anpassen. |
| <b>Anzahl der Drips-Samples:</b> | Menge der Tropfenstichproben anpassen. |
| <b>Drips-Smoothness:</b> | Die Smoothness der Tropfen anpassen. |

### Überblenden

| Parametername | Beschreibung |
| --- | --- |
| <b>Normalintensität:</b> | Passen Sie die Intensität der Normalen-Map-Überblendung an. |
| <b>Ambient occlusion-Intensität:</b> | Passen Sie die Intensität der Überblendung von AO-Maps an. |
| <b>Height-Intensität:</b> | Passen Sie die Intensität der Höhen-Map-Überblendung an. |

**Metallische Rauheit**

| Parametername | Beschreibung |
| --- | --- |
| <b>Intensität der Grundfarbe:</b> | Passe die Grundfarbe an. |
| <b>Intensität der Rauheit:</b> | Passen Sie die Intensität der Überblendung in der Rauheit-Map an. |
| <b>Metallic Intensität:</b> | Passen Sie die Intensität der metallic Kartenüberblendung an. |
