## Beschreibung

Der MatFX Aquarellfilter stilisiert die Quelle mit einem Aquarell-Look.

Es wird auf Textur-Ebenen verwendet, um Aquarellblutungen, Papierinteraktionen und weich gemalte Kanten zu erzeugen.

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Malen-Deckkraft:</b> | Passen Sie die Deckkraft des Malen an. |
| <b>Absorption:</b> | Stellen Sie ein, wie stark das Papier den Malen aufnimmt. |
| <b>Akkumulationstyp:</b> | Wählen Sie die Akkumulationsmethode aus. |
| <b>Borders Spread:</b> | Passen Sie die Verteilung der Malen-Rahmen an. |
| <b>Randdichte:</b> | Passen Sie die Dichte der Malen-Rahmen an. |
| <b>Malen mit Überkreuz anzeigen:</b> | Anzeige von Cross-Malen-Kanten ein/aus. |
| <b>Papier ausblenden:</b> | Schaltet die Sichtbarkeit der Textur um. |
| <b>Benutzerdefiniertes Papier:</b> | Verwenden Sie eine benutzerdefinierte Textur für Papier. |
