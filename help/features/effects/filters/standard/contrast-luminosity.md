## Beschreibung

Der Kontrast-Luminanz-Filter ist eine einfache Anpassung von Kontrast und Luminanz (Helligkeit).

Es wird entweder direkt auf einer Füllebene oder auf einer Maske (Schwarzweiß-Ausgabe) verwendet, um Kontrast und Luminanz (Helligkeit) zu optimieren.

## Parameter

| Parametername | Beschreibung |

| <b>Kontrast:</b> | Passen Sie den Kontrast/Abfall des Ergebnisses an. |
| <b>Luminanz:</b> | Passe die Luminanz an. |
