## Beschreibung

Der Filter Schlagschatten erstellt einen Schlagschatten.

Es wird auf einer Malebene verwendet, um Schlagschatten auf der Grundlage Ihrer gemalten Striche zu erstellen.

<a name="parameters"></a>

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Winkel:</b> | Passen Sie den Schattenwinkel an. |
| <b>Entfernung:</b> | Passen Sie den Schattenabstand an. |
| <b>Größe:</b> | Passe die Schattengröße an. |
| <b>Druckbogen:</b> | Passen Sie die Ausdehnung des Schattens an. |
| <b>Deckkraft:</b> | Passen Sie die Schattendeckkraft an. |
| <b>Farbe:</b> | Passen Sie die Schattenfarbe an. |
