## Beschreibung

Der Umkehrfilter kehrt Farben um. Jeder Kanal außer Alpha wird invertiert.

Sie wird entweder direkt auf einer Füllebene oder auf einer Maske verwendet, um bestimmte Kanäle umzukehren.
