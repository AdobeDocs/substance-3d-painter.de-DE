## Beschreibung

Der Hochpassfilter führt einen Hochpasseffekt durch, ähnlich wie die Photoshop-Aktion mit demselben Namen. Es eignet sich zum Entfernen großer Bildunterschiede bei der Luminanz, z. B. beim Reinigen von Texturen für die Kachelung.

Sie wird auf einer Textur- oder Maskenebene verwendet, um große Unterschiede zwischen den Luminanzen zu entfernen.

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Farbraum:</b> | Wählen Sie den vom Filter verwendeten Farbraum aus. |
| <b>Radius:</b> | Passen Sie den Hochpassradius an. |
| <b>Auf Alpha anwenden:</b> | Stellt ein, ob sich der Filter auf den Alphakanal auswirkt. |
