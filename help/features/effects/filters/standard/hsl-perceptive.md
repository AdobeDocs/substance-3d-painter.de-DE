## Beschreibung

Der HSL Perceptive-Filter passt den Farbton, die Sättigung und die Helligkeit an.

Es wird auf einer Farbebene verwendet, um Textur, Farbton, Sättigung und Helligkeit anzupassen.

<a name="parameters"></a>

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Modus:</b> | Wählen Sie den HSL aus. **Perceptive** passt die Werte entsprechend unserer Farbwahrnehmung an, während **Regular** die Werte entsprechend der internen Darstellung der Farbe auf dem Computer anpasst. |
| <b>Farbton:</b> | Farbton anpassen. |
| <b>Sättigung:</b> | Passe die Sättigung an. |
| <b>Helligkeit:</b> | Passe die Helligkeit an. |
