## Beschreibung

Der Filter &quot;Leuchten&quot; erzeugt einen äußeren Leuchteffekt um die sichtbaren Teile der Eingabe.

Er wird auf einer Maskenebene oder innerhalb einer Textur verwendet (Schwarzweißausgabe), um Formen und Materialien weich oder präzise umleuchten zu lassen.

<a name="parameters"></a>

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Wird für eine Maske verwendet:</b> | Stellt ein, ob das Leuchten auf einer Maske verwendet wird. |
| <b>Modus:</b> | Wählen Sie aus, ob für den Leuchteffekt der Modus &quot;Weich&quot; oder &quot;Präzise&quot; verwendet wird. |
| <b>Breite:</b> | Passen Sie die Breite des Leuchteffekts an. |
| <b>Druckbogen:</b> | Passen Sie die Verteilung des Leuchteffekts an. |
| <b>Deckkraft:</b> | Passen Sie die Deckkraft des Leuchteffekts an. |
| <b>Farbe:</b> | Passen Sie die Leuchtefarbe an. |
