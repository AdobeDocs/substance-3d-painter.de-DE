## Beschreibung

Mit dem Histogramm Scan-Filter werden Kontrast und Helligkeit eines Graustufenbilds neu zugeordnet.

Es wird entweder direkt auf einer Füllebene oder auf einer Maske (Schwarzweiß-Ausgabe) verwendet, um den Kontrast und die Helligkeit anzupassen.

<a name="parameters"></a>

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Position:</b> | Passen Sie die Position des Histogramms an. |
| <b>Kontrast:</b> | Passen Sie den Kontrast/Abfall des Ergebnisses an. |
| <b>Position umkehren:</b> | Umkehren der Position umschalten. Bei sehr hohen oder sehr niedrigen Positionswerten kehrt sich dadurch die Ausgabe effektiv um. |
