## Beschreibung

Der Filter &quot;Schwellenwert&quot; gibt Weiß zurück, wenn die im Parameter &quot;Modus&quot; festgelegten Vergleichskriterien für den Eingabepixelwert relativ zum Schwellenwert erfüllt sind. Es ist ähnlich wie Histogramm Scan, aber mit Kontrast immer auf seinem maximalen Niveau, bietet eine schnellere und präzisere Möglichkeit, ähnliche Ergebnisse zu erzielen.

Es wird entweder direkt auf einer Füllebene oder auf einer Maske (Schwarzweißausgabe) verwendet, um schnell eine Maske mit hohem Kontrast aus bestimmten Kanälen zu erstellen.

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Schwellenwert:</b> | Passen Sie den Wert der Luminanz an, mit der der eingegebene Pixelwert verglichen wird. |
| <b>Modus:</b> | Wählen Sie das Vergleichskriterium für den Schwellenwert aus: Größer, Größer oder gleich, Niedriger oder Niedriger oder gleich. |
| <b>_mode:</b> | Wählen Sie den Wert für den internen Modus aus. |
| <b>_Schwellenwert:</b> | Passen Sie den internen Schwellenwert an. |
| <b>_Threshold_Min:</b> | Passen Sie den internen Schwellenwert an. |
| <b>_Threshold_Max:</b> | Passen Sie den internen maximalen Schwellenwert an. |
