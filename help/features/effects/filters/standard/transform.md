## Beschreibung

Mit dem Transformieren Filter wird eine Ebene transformieren (skaliert, gedreht, versetzt).

Es wird auf einer Maskenebene oder innerhalb einer Textur (Schwarzweiß-Ausgabe) verwendet, um z. B. Muster, Formen usw. transformieren.

<a name="parameters"></a>

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Wiederholungsmodus:</b> | Wählen Sie den Wiederholungsmodus aus. |
| <b>Kippmodus:</b> | Wählen Sie den Spiegeln-Modus aus. |
| <b>Skalierung von X:</b> | Passen Sie die X-Skalierung des Ergebnisses an. |
| <b>Skalierung von Y:</b> | Passen Sie die Y-Skalierung des Ergebnisses an. |
| <b>Versatz X:</b> | Passen Sie den X-Versatz des Ergebnisses an. |
| <b>Versatz Y:</b> | Passen Sie den Y-Versatz des Ergebnisses an. |
| <b>Sichere Drehung der Kachel:</b> | Umschalten der kachelsicheren Drehung. |
| <b>Drehung:</b> | Passe die Drehung an. |
| <b>Skalierung:</b> | Passen Sie die Gesamtskalierung an. |
| <b>Offset:</b> | Passen Sie den Gesamtversatz an. |
