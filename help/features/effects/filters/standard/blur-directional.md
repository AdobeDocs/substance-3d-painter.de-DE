## Beschreibung

Der Weichzeichnungsfilter ist ein sehr einfacher Filter zum Weichzeichnen von Karten oder Masken in einer bestimmten Richtung.

Es wird entweder direkt auf einer Textur-Ebene verwendet, um z. B. vollständige Materials oder bestimmte Texturen zu weichzeichnen. Sie kann auch auf einer Maske verwendet werden, um eine Maske zu weichzeichnen.
