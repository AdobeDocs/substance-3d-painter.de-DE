## Beschreibung

Der Filter &quot;Farbverlauf dynamisch&quot; ordnet die Graustufenwerte in einem Bild einem Farbverlauf neu zu, der durch Farben definiert wird, die an bestimmten Punkten entlang des Farbverlaufs platziert werden.

Sie wird auf einer Maskenebene oder innerhalb einer Textur (Schwarzweißausgabe) verwendet, um Graustufenwerte mit einem aus einem anderen Bild entnommenen Verlauf neu zuzuordnen.

| Eingabename | Beschreibung |
| --- | --- |
| <b>Verlaufsquelle:</b> Farbe | Verwenden einer benutzerdefinierten Farbzuordnung oder eines Ankerpunkts. |

<a name="parameters"></a>

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Verlaufsausrichtung:</b> | Legen Sie fest, ob die Verlaufsquelle horizontal oder vertikal aufgenommen werden soll. |
| <b>Verlaufseingabeposition:</b> | Passen Sie die Position an, die vom Verlaufseingang abgetastet wurde. |
