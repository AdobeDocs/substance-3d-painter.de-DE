## Beschreibung

Der Filter &quot;Tontrennung&quot; reduziert die Anzahl der Farben oder Farbtöne in einem Bild und erzeugt einen stufenförmigen Look mit prägnanteren Bereichen und Kanten.

Es wird auf Farbebenen oder Texturen (Farb- oder Graustufenmasken) verwendet, um durch Vereinfachen von Farben stilisierte, grafische Looks zu erstellen. Das ist oft nützlich für Poster, Illustrationen oder das Reduzieren von Details für künstlerische Effekte.

## Parameter

| Parametername | Beschreibung |

| <b>Farbanzahl:</b> | Passen Sie die Anzahl der Farbschritte an. |
| <b>Auf Alpha anwenden:</b> | Stellt ein, ob der Alphakanal ebenfalls von diesem Filter beeinflusst wird. |
