## Beschreibung

Der Spiegelfilter ist ein Symmetrie-Filter, mit dem ein Teil der Eingabe kopiert wird.

Es wird auf einer Maskenebene (Textur) oder einer Maske verwendet, um vollständige Materialien, Masken, Formen usw. auf Basis des Spiegelachse zu spiegeln.

</td>
</tr>
</table>

>[!NOTE]
>
> Der Spiegelfilter arbeitet im UV-Raum, daher kann es sinnvoll sein, die 2D-Ansichten im **Viewport** zu öffnen.

<a name="parameters"></a>

## Parameter

| Parametername | Beschreibung |
| --- | --- |
| <b>Anzeigedebug:</b> | Schaltet die Anzeige der Debugansicht ein oder aus. |
| <b>Modus:</b> | Wählen Sie den Spiegelmodus aus. |
| <b>Achse X-Versatz:</b> | Passen Sie den Versatz der X-Achse an. |
| <b>Achse-Y-Versatz:</b> | Versatz der Y-Achse anpassen. |
| <b>Achse X umkehren:</b> | Umkehren auf der X-Achse umschalten. |
| <b>Achse Y umkehren:</b> | Umkehren auf der Y-Achse umschalten. |
| <b>Eckentyp:</b> | Legen Sie fest, wie gespiegelte Ecken gehandhabt werden. |
