## Beschreibung

Der FXAA-Filter (Anti-Aliasing) wendet einen auf dem FXAA-Algorithmus basierenden Anti-Aliasing-Filter an. So reparieren Sie gezackte, verpixelte Kanten an Formen.

Er wird auf einer Maskenebene oder einer Maskenebene (Schwarzweiß-Ausgabe) verwendet, um scharfe, kontrastierte Konturen weniger gezackt zu machen.
