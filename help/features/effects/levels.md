# Tonwertkorrektur

Der Pegel ist ein Effekt, mit dem die Farbbereiche eines Bildes angepasst werden. Es ermöglicht die Balance und Tonung von Farben und/oder Graustufenwerten. Sie können ihn hinzufügen, indem Sie das Effektmenü öffnen:

![](../../assets/level-menu.png)

Auf der Hauptschnittstelle wird ein Histogramm angezeigt (der Farbberg in der Mitte der Schnittstelle), das die Darstellung der Verteilung der Pixel in einem Bild bei jeder Farbintensitätsstufe darstellt. Das Histogramm zeigt Details in den Schatten (linker Teil), den Mitteltönen (mittlerer Teil) und den Glanzlichtern (rechter Teil). Das Histogramm gibt auch einen kurzen Blick auf den Tonwertbereich der Farben, sodass man bestimmen kann, wie dunkel oder hell das Bild ist.

![](../../assets/image2015-3-20-11-24-24.png)

Um den Farbbereich des Bildes anzupassen, stehen am oberen und unteren Rand des Histogramms zwei Gruppen von Steuerelementen zur Verfügung:

* Die drei oberen Schaltflächen steuern die Schatten, Mitteltöne und Glanzlichter und können verwendet werden, um den Tonwertbereich neu zu verteilen, um einen Kontrast zum Gesamtbild herzustellen.
* Die beiden unteren Schaltflächen steuern das Schwarz und den Weißpunkt des Bildes (in der Regel 0 und 255). Dies kann nützlich sein, um beispielsweise die Farben eines Bildes umzukehren.

>[!NOTE]
>
> Der Effekt &quot;Ebenen&quot; kann jeweils nur auf einen Kanal angewendet werden, wie von der Option *Betroffener Kanal* ausgewählt. Wenn du eine Ebene auf mehrere Kanäle anwenden willst, musst du mehrere Effekte auf Ebenen erstellen.

* Mit dem Dropdown-Feld &quot;Farben&quot; (Colors) oben rechts können Sie die Pegel des gesamten RGB-Bildes oder nur eines der Kanäle Rot, Grün und Blau ändern.
* Mit der Option &quot;Beschränk&quot; unten rechts können Sie die Werte der Pegel zwischen 0 und 1 (0-255) einspannen. Diese Option sollte immer aktiviert sein, wenn Sie an Nicht-HDR-Kanälen arbeiten (z. B. **Grundfarbe**).
