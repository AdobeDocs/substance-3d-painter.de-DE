# Updateprüfung

![](../../assets/update-cc.png)

Sie können vom Creative Cloud-Desktop nach Substance 3D Painter-Updates suchen. Navigieren Sie zur Registerkarte Applikationen und sehen Sie sich den Abschnitt Installierte Apps an. **Update verfügbar** wird unter dem App-Namen angezeigt, wenn ein Update zum Download bereit ist.

Sie können auf die Versionshinweise für die aktuelle Version zugreifen, indem Sie Painter öffnen und **Hilfe > Versionshinweise** verwenden.
