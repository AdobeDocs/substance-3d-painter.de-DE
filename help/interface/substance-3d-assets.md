# Substance 3D Assets

![](../assets/v10_banner_3d_assets_2-1.jpg)

Das <b>Substance 3D Assets</b>-Dock ermöglicht das Durchsuchen der Onlinebibliothek mit demselben Namen direkt in der Anwendung. Die Originalbibliothek ist unter folgender Adresse verfügbar: <https://substance3d.adobe.com/assets>

>[!NOTE]
>
> Das Substance 3D Assets-Fenster ist in der Steam-Version der Anwendung nicht verfügbar.

## Standort

Standardmäßig wird das Fenster als Registerkarte neben dem Fenster &quot;Allgemeine Elemente&quot; angedockt. Wenn das Fenster geschlossen ist, kann es über die Dock-Symbolleiste ganz rechts in der Benutzeroberfläche erneut geöffnet werden.

![](../assets/v10_3dassets_location_tab.png)

![](../assets/v10_3dassets_location_dock.png)

### Durchsuchen von Assets

Zum Durchsuchen von Elementen können Sie die im Fenster verfügbare Benutzeroberfläche verwenden. Oben wird ein Suchfeld angezeigt, mit dem Sie Ihre Suche eingrenzen können. Es ist auch ein Filter verfügbar.

![](../assets/v10_3d_assets_search.jpg)

### Herunterladen von Elementen

Sobald Sie auf die Download-Schaltfläche eines Assets klicken, werden diese heruntergeladen und im Download-Manager des Fensters angezeigt. Um es anzuzeigen, klicken Sie einfach auf die untere linke Schaltfläche des Fensters.

In dieser Liste werden nur Elemente angezeigt, die während der aktuellen Sitzung der Anwendung heruntergeladen wurden.

Nachdem ein Asset erfolgreich heruntergeladen wurde, wird es im normalen Fenster <b>Assets</b> angezeigt.

![](../assets/v10_3d_assets_download.png)

>[!NOTE]
>
> Der Speicherort, an dem Ressourcen heruntergeladen werden, hängt von der Standardbibliothek ab. Dieser Speicherort kann in den Voreinstellungen geändert werden. Weitere Informationen finden Sie auf der dedizierten [Dokumentationsseite](assets/adding-a-new-library.md).

### Steuerungsmenü

Die Schaltfläche unten rechts im Fenster bietet einige Aktionen:

* <b>Ordnerpfad öffnen</b>: den Explorer mit der aktuellen Bibliothek öffnen. Dadurch können die heruntergeladenen Assets (einschließlich früherer Sitzungen) auf der Festplatte durchsucht werden.
* <b>Seite </b> neu laden: die Benutzeroberfläche innerhalb des Fensters neu laden.
* <b>Vorherige Seite</b>: zur vorherigen Benutzeroberfläche innerhalb des Fensters navigieren.
* <b>Nächste Seite</b>: zur nächsten Benutzeroberfläche innerhalb des Fensters navigieren.

![](../assets/v10_3d_assets_menu-1.png)
