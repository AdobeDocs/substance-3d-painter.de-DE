# Backlog

Das **Fenster für das Sicherungsprotokoll** zeigt die technische Ausgabe im Zusammenhang mit dem Sichern an. Das Bedienfeld enthält drei Registerkarten:

* **Backvorgang**: Siehe den Status laufender Backaufgaben oder den neuesten Backvorgang.
* **Hohe Poly-Parameter**: Hier finden Sie Details zu Dateien mit hohem Poly-Wert, die in Ihrem Projekt verwendet werden.
* **Übereinstimmung nach Name**: Wenn **Hohe Poly-Parameter > Übereinstimmung** auf **Nach Netzname** festgelegt ist, zeigt diese Registerkarte Informationen darüber an, wie Assets zugeordnet wurden.

>[!TIP]
>
> Informationen zum Abgleichen von Assets nach Namen finden Sie in [der Bakers-Dokumentation](https://experienceleague.adobe.com/de/docs/substance-3d/bakers/features/matching-by-name).
