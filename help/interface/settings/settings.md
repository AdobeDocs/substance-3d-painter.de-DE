# Einstellungen

![](../../assets/settings-general.png){width="400px"}

Öffnen Sie die <b>Einstellungen </b> im Menü <b>Bearbeiten </b>, um Ihre Einstellungen für die Arbeit mit Painter anzupassen.

Die <b>Einstellungen </b> sind in drei Abschnitte unterteilt:

* [Allgemeine Voreinstellungen](general-preferences.md)
* [Tastaturkürzel](shortcuts.md)
* [Bibliothekskonfiguration](libraries-configuration.md)
