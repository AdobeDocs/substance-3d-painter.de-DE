# JavaScript- und Python-Plug-in-Menüs

![](../../assets/plugins-javascript.png)

In den JavaScript- und Python-Menüs werden alle Plug-ins aufgeführt, die beim Start von Painter geladen werden. Plug-ins werden je nach verwendeter Skript-API in zwei Menüs aufgeteilt (Javascript oder Python).

Jedes von der Anwendung entdeckte Plug-in fügt einen Eintrag im entsprechenden Menü hinzu, um auf zusätzliche Funktionen zuzugreifen. In den Menüs stehen für jedes Plug-in die folgenden Optionen zur Verfügung:

* **Deaktivieren/Aktivieren**: das Plug-in aktivieren oder deaktivieren.
* **neu laden**: Laden Sie das Plug-in neu, falls das Skript aktualisiert wurde, während die Anwendung ausgeführt wurde.
* **Konfiguration**: zeigt die Funktion/das Fenster an, um das Plug-in zu konfigurieren, falls es vom Plug-in unterstützt wird.
* **Info**: Wenn es vom Plug-in unterstützt wird, werden Informationen zum Plug-in angezeigt.

Weitere Informationen zu den Standard-Plug-ins in Painter oder zur Erstellung neuer Plug-ins finden Sie auf der dedizierten Seite [Plug-ins](../../features/plugins/plugins.md).
