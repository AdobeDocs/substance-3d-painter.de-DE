# Viewport-Menü

![](../../assets/viewport-menu.png)

Das Viewport-Menü kann verwendet werden, um den Anzeigemodus von [Viewports](https://substance3d.adobe.com/) zu ändern.

| Aktion | Beschreibung |
| --- | --- |
| **Material anzeigen** | Wechseln Sie in den Ansichtsmodus **Material**, in dem das 3D-Modell mit Beleuchtung und Schattierung angezeigt wird. |
| **Nächsten Kanal anzeigen** | Schalten Sie die Viewports in den Solo-Modus um, um den nächsten Textursatz-Kanal anzuzeigen. |
| **Vorherigen Kanal anzeigen** | Wechseln Sie in den Solomodus der Viewports, um den vorherigen Textursatz-Kanal anzuzeigen. |
| **Nächste Netzzuordnung anzeigen** | Wechseln Sie in den Solo-Modus, um den nächsten gebackenen Mesh-Map-Typ anzuzeigen. |
| **Vorherige Gitterzuordnung anzeigen** | Wechseln Sie in den Solo-Modus, um den vorherigen getackten Mesh-Map-Typ anzuzeigen. |
| **Gesamtes Gitter anzeigen** | Passen Sie die Viewport-Kamera an, um sie auf dem 3D-Modell zu zentrieren. |
| **Schnellmaske aktiviert** | Weitere Informationen finden Sie auf der Seite [Schnellmaske](../../painting/tool-list/quick-mask.md). |
| **Schnellmaske bearbeiten** | Weitere Informationen finden Sie auf der Seite [Schnellmaske](../../painting/tool-list/quick-mask.md). |
| **Kurzmaske umkehren** | Weitere Informationen finden Sie auf der Seite [Schnellmaske](../../painting/tool-list/quick-mask.md). |

Weitere Informationen zu den Anzeigemodi finden Sie unter [Anzeigeeinstellungen](../display-settings/display-settings.md).

Weitere Informationen zur Schnellmaske finden Sie auf der [dedizierten Seite](../../painting/tool-list/quick-mask.md).
