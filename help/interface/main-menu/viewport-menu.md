# Menü &quot;Viewport&quot;

![](../../assets/viewport-menu.png)

Mit dem Menü &quot;Viewport&quot; kann der Anzeigemodus der [Viewport](https://substance3d.adobe.com/) geändert werden.

| Aktion | Beschreibung |
| --- | --- |
| **Material anzeigen** | Wechseln Sie die Viewport in den Modus **Material**, in dem das 3D-Modell mit Beleuchtung und Schattierung angezeigt wird. |
| **Nächsten Kanal anzeigen** | Wechseln Sie in den Solo-Viewport, um den nächsten Textursatz-Kanal anzuzeigen. |
| **Vorherigen Kanal anzeigen** | Wechseln Sie zu den Viewporten in den Solo-Modus, um den vorherigen Textursatz-Kanal anzuzeigen. |
| **Nächste Mesh-Map anzeigen** | Wechseln Sie zu den Viewporten in den Solo-Modus, um den nächsten Baking geführt Mesh-Map-Typ anzuzeigen. |
| **Vorherige Mesh-Map anzeigen** | Wechseln Sie zu den Viewporten in den Solo-Modus, um den zuvor Baking geführt Mesh-Map-Typ anzuzeigen. |
| **Gesamten Mesh anzeigen** | Passen Sie die Kamera des Viewports an, um ihn auf dem 3D-Modell zu zentrieren. |
| **schnelle Maske aktiviert** | Weitere Informationen finden Sie auf der Seite [Schnellmaske](../../painting/tool-list/quick-mask.md). |
| **schnelle Maske bearbeiten** | Weitere Informationen finden Sie auf der Seite [Schnellmaske](../../painting/tool-list/quick-mask.md). |
| **schnelle Maske umkehren** | Weitere Informationen finden Sie auf der Seite [Schnellmaske](../../painting/tool-list/quick-mask.md). |

Weitere Informationen zu den Anzeigemodi finden Sie unter [Anzeigeeinstellungen](../display-settings/display-settings.md).

Weitere Informationen zur Schnellmaske finden Sie auf der [dedizierten Seite](../../painting/tool-list/quick-mask.md).
