# Hilfemenü

<table style="table-layout:auto">
  <tr style="border: 0;">
    <td style="border: 0;" valign="top">Das Hilfemenü enthält Links und Optionen, über die Sie weitere Informationen zu Substance 3D Painter erhalten. Dazu gehören hilfreiche Inhalte wie Tutorials, Versionshinweise und Dokumentation oder Orte, an denen Sie Probleme mit Ihrer lokalen Installation von Painter beheben können, einschließlich des Zugriffs auf die Protokolle oder einer Möglichkeit, Fehler zu melden.</td>

| Dokumentation | Link zu dieser Dokumentation. |
| Liste der Tastaturbefehle | Link zur Dokumentation [shortcuts](../settings/shortcuts.md). |

| Abmelden | Melden Sie sich vom derzeit angemeldeten Adobe-Konto ab. |
| Startbildschirm | Öffnen Sie das Fenster [Begrüßungsbildschirm](../../getting-started/getting-started.md). |
