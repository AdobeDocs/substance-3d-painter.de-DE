# Dateimenü

![](../../assets/file-menu.png){width="150px"}

Das Dateimenü enthält die Aktionen zum Erstellen und Speichern der Projekte sowie die Aktionen zum Exportieren und Importieren von Ressourcen in ein Projekt.

| Aktion | Beschreibung |
| --- | --- |
| **Neu** | Öffnen Sie das Fenster zum Erstellen eines neuen Projekts. Siehe: [Projekterstellung](../../getting-started/project-creation.md)für weitere Informationen. |
| **Offen** | Öffnen Sie eine vorhandene Projektdatei auf der Festplatte. |
| **Zuletzt verwendete Dateien** | Listet alle kürzlich geöffneten Projekte auf. |
| **Beispiel öffnen** | Öffnen Sie eines der mit der Anwendung bereitgestellten Beispielprojekte. |
| **Schließen** | Schließen Sie das derzeit geöffnete Projekt. |
| **Speichern** | Speichern Sie das aktuelle Projekt an Ort und Stelle. |
| **Speichern und komprimieren** | Speichern Sie das aktuelle Projekt an Ort und Stelle und komprimieren Sie es (verringern Sie den Speicherbedarf auf der Festplatte). |
| **Speichern unter** | Speichern Sie das aktuelle Projekt unter einem neuen Namen und Speicherort. |
| **Als Kopie speichern** | Speichern Sie das aktuelle Projekt unter einem neuen Namen und unter einem neuen Speicherort als Kopie, und lassen Sie das aktuelle Projekt geöffnet. |
| **Als Vorlage speichern** | Speichern Sie die aktuellen Projekteinstellungen in einer Vorlagendatei, die für ein neues Projekt verwendet werden kann. |
| **Bereinigen** | Entfernen Sie alle nicht verwendeten Ressourcen aus dem aktuellen Projekt (wird nach dem nächsten **Speichern** wirksam). |
| **Ressourcen importieren** | Öffnen Sie das Importressourcenfenster. |
| **Gitter exportieren** | Öffnen Sie das Fenster &quot;Gitterexport&quot;, in dem Sie das aktuelle Projekt als 3D-Modelldatei exportieren können. |
| **Texturen exportieren** | Öffnen Sie das Fenster Texturexport , in dem Sie das aktuelle Projekt als Bitmaptexturen exportieren können. |
| **Senden an** | Listet alle **Aktionen zum Senden an** auf, um ein Projekt an eine andere Anwendung zu senden. |
| **Beenden** | Schließen Sie die Anwendung. Wenn das aktuelle Projekt nicht gespeicherte Änderungen enthält, wird eine Meldung angezeigt. |

>[!NOTE]
>
> Das Speichern eines Projekts kann auf zwei Arten erfolgen:
> 
> * **Inkrementell** : Standardmethode, die beim Speichern verwendet wird. Nur die geänderten Informationen werden in der Projektdatei auf der Festplatte aktualisiert. Mit dieser Methode kann das Projekt sehr schnell gespeichert werden, ohne dass die Projektdatei vollständig neu geschrieben werden muss.
> * **Voll/Kompakt** : Wenn ein Bereinigungsvorgang ausgeführt wird oder wenn das Projekt mit der Aktion &quot;Speichern und komprimieren&quot; gespeichert wird, schreibt die Methode das Projekt vollständig auf die Festplatte um. Mit dieser Methode können Sie die Projektfragmentierung beseitigen und den Platzbedarf reduzieren. Siehe: [Projekte sind wirklich groß](../../technical-support/workflow-issues/project-issues/projects-are-really-big.md).
