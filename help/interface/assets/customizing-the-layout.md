# Layout anpassen

Es gibt einige Optionen auf der Benutzeroberfläche, z. B. Unterbibliotheken, reduzierte Breite und Miniaturgröße, mit denen Sie das Layout des Bedienfelds &quot;Elemente&quot; an Ihre Anforderungen anpassen können.

>[!NOTE]
>
> Elemente können mit dem Mausrad oder durch Bearbeiten der Bildlaufleiste durchblättert werden. Alternativ können Sie in einem beliebigen Painter-Fenster einen Bildlauf durchführen, indem Sie Strg + Alt gedrückt halten und **im gewünschten Bedienfeld ziehen.**

Andocken und Ausrichtung

Wenn Sie Painter nach der Installation zum ersten Mal öffnen, wird das Asset-Fenster vertikal auf der linken Seite der App angedockt. Es kann jedoch abgedockt und horizontal platziert werden. Wenn Sie weitere [Sub-Library](sub-library-tab.md)-Fenster verwenden, können auch diese nach Belieben an- und abgedockt werden.

![](../../assets/00-02-docking.gif){width="600px"}

## Reduzierte Breite

Die Größe kann reduziert werden. In diesem Fall werden die Elementtypen in einem einzigen Menü zusammengefasst, in dem Sie eine oder mehrere Optionen auswählen können.

![](../../assets/00-03-reduced.jpg)

## Miniaturgröße

Die Größe der Miniaturansichten von Elementen kann über das Symbol ganz links angepasst werden, das die Optionen Klein, Mittel (Standard), Groß und Liste bietet.

![](../../assets/00-04-thumbs.jpg){width="600px"}
