# Probleme mit Nvidia-GPUs in den neuesten Mac OS-Versionen

Unter Mac OS stellt Apple die GPU-Treiber bereit, indem es sie nach der Bereitstellung durch den GPU-Konstruktor überprüft. Seit Mac OS Mojave hat Apple noch keine neuen Treiber für die neuesten Nvidia-GPUs validiert. Leider benötigt Substance 3D Painter einen aktuellen Grafikprozessor, damit die Treiber richtig funktionieren.

Weitere Informationen finden Sie auf der folgenden Seite:

* [Liste der unterstützten GPUs unter Mac OS](https://support.apple.com/en-us/HT208898) .
* [Verwendung einer externen GPU unter Mac OS](https://support.apple.com/en-us/HT208544) .
