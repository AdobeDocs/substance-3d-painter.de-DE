# Fehler: Es ist kein Datenträger im Laufwerk vorhanden.

Unter Windows kann dieser Fehler auftreten:

&quot;Es befindet sich kein Datenträger im Laufwerk. Legen Sie eine Diskette in Laufwerk X ein.&quot;

![](../../../assets/disk-drive-error.png)

Es gibt einige Dinge zu überprüfen, um diesen Fehler zu entfernen:

* Vergewissern Sie sich, dass Ihre Laufwerkbuchstaben richtig eingerichtet sind (siehe <https://support.microsoft.com/en-us/kb/330137> ).
* Überprüfen Sie, ob alle zuvor in Substance 3D Painter verwendeten Speicherorte gültig sind (z. B. die Liste der zuletzt verwendeten Dateien).
