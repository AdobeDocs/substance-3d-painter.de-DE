# Dateien können nicht per Drag &amp; Drop in das Regal verschoben werden

Unter **Windows 8 und Windows 10** , wenn Sie Substance 3D Painter im Administratormodus ausführen, ist die Sicherheitsstufe der Software wahrscheinlich höher als die Sicherheitsstufe von Windows Explorer. Daher kann Windows Dateien nicht per Drag &amp; Drop zwischen diesen Anwendungen verschieben.

Um dieses Problem zu beheben, können Sie entweder

* Substance 3D Painter normal ausführen (ohne Administratorrechte).
* Deaktivieren Sie die Benutzerkontensteuerung (dies ist **nicht empfohlen** ).

>[!NOTE]
>
> Es ist auch möglich, Ressourcen zu importieren, indem Sie einfach das Importfenster öffnen:
> 
> 1. Klicken Sie auf das Menü &quot;Datei&quot;
> 1. Wählen Sie &quot;Ressourcen importieren...&quot;
> 1. Klicken Sie im Importfenster auf &quot;Ressourcen hinzufügen&quot;, um Ihre Dateien auszuwählen
