# Exportieren eines DXDiag

Auf dieser Seite wird erläutert, was ein DXDiag ist und wie es generiert wird.

Das DXDiag ist eine unter Windows erstellte Diagnose, die Informationen zu Ihrem Computer und Ihrem GPU-Setup enthält.

Führen Sie die folgenden Schritte aus, um es auf Anfrage des Support-Teams zu exportieren:

1. Gehen Sie zu Start > Ausführen und geben Sie **&quot;dxdiag&quot;** (ohne Anführungszeichen) in das Feld **&quot;Öffnen&quot;** ein und drücken Sie die Schaltfläche OK .
1. Warten Sie, bis die **&quot;green&quot;**-Fortschrittsleiste vollständig geladen ist, und drücken Sie dann die Taste **&quot;Save All Information...&quot;** Knopf
1. Benennen Sie die Datei mit nützlichen Informationen wie Ihrem Namen und dem Datum und speichern Sie sie dort, wo Sie sie finden können, wie auf dem Desktop, indem Sie auf die Schaltfläche **&quot;Speichern&quot;** klicken.
1. Drücken Sie die Schaltfläche **&quot;Exit&quot;**, um diese Anwendung zu beenden.
