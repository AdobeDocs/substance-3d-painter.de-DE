# Exportieren der Protokolldatei

Auf dieser Seite wird erläutert, wie Sie die Anwendungsprotokolldatei finden und freigeben können, um Unterstützung zu erhalten.

## Protokolldatei wird abgerufen

Es gibt zwei Möglichkeiten, die Protokolldatei abzurufen:

### Exportieren der Protokolldatei aus der Anwendung

Die Protokolldatei kann direkt aus der Anwendung exportiert werden, indem Sie im Menü **Hilfe** die Aktion **Protokoll exportieren** auswählen.

![](../assets/screenshot-20210622-195334.png)

### Die Protokolldatei wird manuell auf der Festplatte abgerufen.

Wenn die Anwendung nicht gestartet wird, kann die Protokolldatei nicht exportiert werden. Glücklicherweise kann die Protokolldatei manuell auf der Festplatte gespeichert werden. Navigieren Sie zu dem Ordner, der mit Ihrem Betriebssystem übereinstimmt, und rufen Sie die Datei **log.txt** manuell ab.
