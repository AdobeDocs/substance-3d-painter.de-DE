# Laden von Dateien aus einem Netzwerk

Substance 3D Painter unterstützt keine Netzwerkpfade, da hierfür eine **Kontoauthentifizierung** erforderlich ist, was die Software nicht kann.\
Daher müssen die Pfade vom Betriebssystem **zugeordnet** / **bereitgestellt** sein.

* **Windows** : 2<http://www.laptopmag.com/articles/map-network-drive-windows-10>
* **MacOS** : 2<http://osxdaily.com/2010/09/20/map-a-network-drive-on-a-mac/>
* **Linux** : 2<http://superuser.com/questions/145191/how-do-i-map-a-drive-network-share-using-the-linux-terminal>
