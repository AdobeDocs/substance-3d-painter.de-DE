# Ausgefüllter Pfad

![](../../assets/banner_filled_path.jpg)

Das Pfadwerkzeug ist ein Pfadwerkzeug, mit dem Sie Formen auf der Oberfläche des 3D-Modells erstellen können, die mit einer einheitliche Farbe gefüllt sind.

![](../../assets/filled_path_across_gaps.png)

Auf das Tool &quot;<b>Ausgefüllter Pfad</b>&quot; kann über das Menü &quot;Pfadwerkzeuge&quot; zugegriffen werden:

![](../../assets/filled_path_menu.png)

## Einstellungen

Die Einstellungen für die Pfadfüllung sind:

| Einstellung | Beschreibung |
| --- | --- |
| Deckkraft | Legen Sie die Deckkraft der gefüllten Form fest. |
