# Erstellen und Speichern von Vorgaben

Verwenden Sie das [Eigenschaftenfenster](../../interface/properties.md), um die Pinselparameter zu optimieren, und speichern Sie dann die Pinselkonfiguration als Vorgabe, um sie in Zukunft schnell wiederzuverwenden.

>[!NOTE]
>
> Mit dem [Pfad-Werkzeug](../tool-list/path.md) ist im [Eigenschaftenfenster](../../interface/properties.md) ein Vorgabenbereich verfügbar, in dem Sie schnell auf pfadbezogene Vorgaben zugreifen können. Sie können Ihren Favoriten auch Pfadvorgaben hinzufügen. Weitere Informationen zum Verwalten Ihrer bevorzugten [Pfadvorgaben finden Sie hier](../tool-list/path.md).

## Neue Vorgabe erstellen.

![](../../assets/save-preset-1.png)

Wenn Werkzeugeigenschaften verfügbar sind (Malebene oder Maleffekt), können Vorgaben durch Rechtsklick auf das Eigenschaftenfenster erstellt werden.

Klicken Sie mit der rechten Maustaste in das Eigenschaftenfenster, um ein Kontextmenü mit den folgenden Optionen zu öffnen:

* <b>Werkzeugvorgabe erstellen</b> : Speichern Sie die Pinselparameter und die Materialien mit allen erforderlichen Ressourcen in derselben Vorgabedatei.
* <b>Materialvorgabe erstellen</b> : Speichern Sie nur die Materialeigenschaften und Materialressourcen innerhalb einer Vorgabedatei.
* <b>Pinselvorgabe erstellen</b> : Speichern Sie nur die Pinselparameter sowie die Alpha- und Schablonenressourcen in einer voreingestellten Datei.

## Aktualisieren einer vorhandenen Vorgabe

![](../../assets/update-preset.png)

Es ist möglich, eine vorhandene Vorgabe basierend auf den aktuellen Werten im Eigenschaftenfenster zu aktualisieren. Klicken Sie mit der rechten Maustaste auf das Asset im Fenster [Assets](../../interface/assets/assets.md) und wählen Sie &quot;Vom aktuellen Tool aktualisieren&quot;, um die Vorgabe zu aktualisieren.
