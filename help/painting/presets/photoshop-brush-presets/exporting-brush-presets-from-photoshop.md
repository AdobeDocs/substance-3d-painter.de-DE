# Exportieren von Pinselvorgaben aus Photoshop

ABR-Dateien (Photoshop-Pinselvorgaben) können nur von Adobe Photoshop aus erstellt werden. So erstellen Sie eine ABR mit Vorgaben:

1. <b>Adobe Photoshop öffnen.</b>

   ABR-Dateien können nur in Photoshop erstellt werden.
1. <b>Öffnen Sie das Pinselbedienfeld.</b>

   Öffnen Sie das Pinselbedienfeld unter <b>Fenster > Pinsel. </b>

   ![](../../../assets/photoshop-brush-window.png){width="500px"}
1. <b>Wählen Sie die Pinselvorgaben (oder Gruppen) aus, die exportiert werden sollen.</b>

   Halten Sie STRG gedrückt, um mehrere Pinsel oder Vorgaben auszuwählen.

   ![](../../../assets/photoshop-preset-selection.gif){width="500px"}
1. <b>In eine ABR-Datei exportieren.</b>

   Öffnen Sie das Menü &quot;Einstellungen&quot; im Pinselfenster und wählen Sie <b>Ausgewählte Pinsel exportieren</b>.

   Es wird ein Dateidialogfeld angezeigt, in dem Sie nach einem Dateinamen und einem Speicherort zum Speichern der exportierten ABR-Datei gefragt werden.

   ![](../../../assets/photoshop-export-presets-menu.png)
