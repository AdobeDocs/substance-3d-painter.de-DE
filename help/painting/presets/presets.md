# Voreinstellungen

Eine Vorgabe ist eine gespeicherte Konfiguration von [Malwerkzeugen](../../painting/tool-list/tool-list.md). Sie können eine von drei verschiedenen Arten haben:

* **Pinselvorgabe** : Speichert die Pinselparameter (Größe, Fluss, Jitter, Schablone und Alpha).
* **Materialvorgabe** : Speichert die Material-Eigenschaften (Einzelkanäle und Substance-Dateien).
* **Werkzeugvorgabe** : Speichert die Eigenschaften &quot;Pinsel&quot; und &quot;Material&quot; sowie den verwendeten Werkzeugtyp (Malen, Verwischen, Klon usw.).

Vorgaben werden auf dem Datenträger im Ordner &quot;[Elemente](../../interface/assets/assets.md)&quot; gespeichert. Sie können ganz einfach zwischen Computern kopiert werden, da sie alle von ihnen verwendeten Ressourcen einbetten.

Informationen zum Verwalten Ihrer Vorgaben finden Sie unter:

* [Erstellen und Speichern von Vorgaben](https://helpx.adobe.com/substance-3d/unlisted/documentation/spdoc/creating-and-saving-a-preset-180191514.html)
* [Erstellen von Partikeln-Vorgaben](../../painting/presets/creating-particles-pre/creating-particles-presets.md)
* [Photoshop-Pinselvorgaben (ABR)](../../painting/presets/photoshop-brush-presets/photoshop-brush-presets-abr.md)
