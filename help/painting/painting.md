# Malen

Das Malen in Substance 3D Painter kann auf vielerlei Weise mit manuellen Werkzeugen oder automatischen Aktionen erfolgen.

Die manuellen Malwerkzeuge sind direkt über die Symbolleiste (oder ihren dedizierten Tastaturbefehl) zugänglich. Wenn ein Malen-Werkzeug ausgewählt ist, werden seine Eigenschaften im Eigenschaftenfenster angezeigt.
