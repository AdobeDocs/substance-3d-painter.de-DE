# Standard-Ausgabevorlagen

Im Folgenden finden Sie eine Liste zusätzlicher Ausgabevorlagen, die standardmäßig bereitgestellt werden.  Standardmäßige Ausgabevorlagen können kopiert und auf der Registerkarte <b>Ausgabevorlagen </b> des <b>Exportfensters</b> geändert werden.

>[!NOTE]
>
> Einige andere Software, die hier nicht aufgeführt ist, wird möglicherweise ebenfalls unterstützt (z. B. **Octane**). Weitere Informationen finden Sie im [Ökosystem und Plug-Ins](https://experienceleague.adobe.com/en/docs/substance-3d/ecosystem/home).

| *Vorgabe* | *Beschreibung* |
| --- | --- |
| <b> Amazon Lumberyard </b> | Benennen und verpacken Sie die Texturen, die in Amazon Lumberyard importiert und verwendet werden sollen. |
| <b> Arnold (AiStandard) </b> | Vorgabe für Arnold (AiStandard Shader). |
| <b> Arnold UDIM Legacy (AiStandard)</b> | Vorgabe für Arnold UDIM Legacy (AiStandard). |
| <b>Blender (Principled BSDF)</b> | Vorgabe für Mischmodus (Principled BSDF). |
| <b> Corona </b> | Vorgabe für den Renderer &quot;Corona&quot;. |
| <b> CryEngine 3 </b> | Benennen und verpacken Sie die Texturen, die importiert und in Cry Engine 3 verwendet werden sollen. |
| <b> Dota 2 </b> | Vorgabe für das Spiel Dota 2 (kann mit der zugehörigen Vorlage verwendet werden). |
| <b> Keyshot </b> | Vorgabe für den Renderer &quot;Keyshot&quot;. |
| <b>Keyshot 9+</b> | Voreinstellung für den Renderer &quot;Keyshot&quot; ab Version 9. |
| <b> Linsenstudio </b> | Vorgabe für Lens Studio (zum Erstellen von Elementen für Snapchat). |
| <b>Maxwell (Metallische Rauheit)</b> | Vorgabe für den Maxwell-Renderer mithilfe des Metallische Rauheit-Workflows. |
| <b>Maxwell (Specular-Glanz)</b> | Vorgabe für den Maxwell-Renderer mithilfe des Specular-Glanz-Workflows. |
| <b> Mesh-Map </b> | Exportieren Sie die Baking geführt Mesh-Map-Slots eines Textursatzes einzeln (exportiert in der gleichen Auflösung wie für den Textursatz). |
| <b>Nicht-PBR-Specular-Glanz</b> | Benennen und exportieren Sie Texturen für einen Nicht-PBR-Specular-Glanz-Workflow. |
| <b> PBR-Metallische Rauheit </b> | Benennen und exportieren Sie die Texturen, die für einen regulären PBR-Arbeitsablauf mit Metallic und Rauheit erforderlich sind. |
| <b> PBR-Metallische Rauheit (Ordner oder PSD-Gruppen) </b> | Ähnlich wie PBR MetalRough, jedoch wird ein zusätzlicher Ordner erstellt. Diese Vorgabe eignet sich hauptsächlich für die Verwendung mit dem PSD-Dateiformat. |
| <b> PBR Specular-Glanz</b> | Benennen und exportieren Sie die Texturen, die für einen regulären PBR-Arbeitsablauf für Specular/Glanz erforderlich sind. (Die Texturen werden aus dem BaseColor-/Metallic Workflow konvertiert.) |
| <b> PBR-Specular-Glanz (konvertiert aus Metallische Rauheit</b>) | Konvertieren Sie Grundfarben-, Metallic und Rauheit-Kanäle so, dass sie mit dem Specular-/Glissiness-Workflow kompatibel sind. |
| <b> Redshift </b> | Vorgabe für den Renderer &quot;Redshift&quot;. |
| <b>Renderman (pxrDisney)</b> | Vorgabe für Renderman mithilfe von Metallic und Rauigkeitsmaps. |
| <b>Renderman (pxrSurface)</b> | Vorgabe für Renderman mithilfe von Diffuse- und Specular-Maps. |
| <b>Roblox (MaterialVariant)</b> | Vorgabe für Roblox mit Albedo ohne Alpha-Unterstützung. |
| <b>Roblox (SurfaceAppearance)</b> | Vorgabe für Roblox unter Verwendung von Colormap mit Alphakanal. |
| <b> 3D </b> schattieren | Vorgabe für &quot;3D schattieren&quot; |
| <b>Spark AR Studio</b> | Vorgabe für Spark AR Studio. |
| <b>Unity HD-Renderpipeline (Metallic Standard)</b> | Voreinstellung für die HD-Renderpipeline von Unity mithilfe von Metallic und Glanz Maps. |
| <b>Unity HD-Renderpipeline (Specular)</b> | Vorgabe für die HD-Renderpipeline von Unity mit hinzugefügter Specular-Map. |
| <b>Universelle Unity-Render-Pipeline (Metallic Standard)</b> | Vorgabe für die universelle Render-Pipeline von Unity mithilfe von Metallic und Smoothnessen-Maps. |
| <b>Universelle Unity-Render-Pipeline (Specular)</b> | Vorgabe für die Universal-Render-Pipeline von Unity mit Specular- und Smoothness-Maps. |
| <b> Unreales Engine (verpackt) </b> | Benennen und verpacken Sie die Texturen, die im Unreal-Engine mit möglichst wenig Speicher verwendet werden sollen. |
| <b>Unreale Engine-SSS (verpackt)</b> | Benennen und verpacken Sie die Texturen, die im Unreal-Engine verwendet werden sollen, mit der geringstmöglichen Speicherauslastung und ersetzen Sie die Deckkraftzuordnung durch die Volumenstreuung. |
| <b> Nächste Variation (Metallische Rauheit)</b> | Voreinstellung für den Vray-Renderer mit PBR-Arbeitsablauf. |
| <b>Nächste Variation (Specular-Glanz)</b> | Vorgabe für den Vray-Renderer mit Nicht-PBR-Arbeitsablauf. |
| <b> Verschiedene UDIM Legacy (Metallische Rauheit)</b> | Vorgabe für den Vray-Renderer (UDIM-Benennungskonvention). |
