# Standard-Ausgabevorlagen

Im Folgenden finden Sie eine Liste zusätzlicher Ausgabevorlagen, die standardmäßig bereitgestellt werden.  Standardmäßige Ausgabevorlagen können kopiert und auf der Registerkarte <b>Ausgabevorlagen </b> des <b>Exportfensters</b> geändert werden.

>[!NOTE]
>
> Einige andere Software, die hier nicht aufgeführt ist, wird möglicherweise ebenfalls unterstützt (z. B. **Octane**). Weitere Informationen finden Sie im [Ökosystem und Plug-Ins](https://experienceleague.adobe.com/en/docs/substance-3d/ecosystem/home).

| *Vorgabe* | *Beschreibung* |
| --- | --- |
| <b> Amazon Lumberyard </b> | Benennen und verpacken Sie Texturen, die in Amazon Lumberyard importiert und verwendet werden sollen. |
| <b> Arnold (AiStandard) </b> | Vorgabe für Arnold (AiStandard-Shader). |
| <b> Arnold UDIM Legacy (AiStandard)</b> | Vorgabe für Arnold UDIM Legacy (AiStandard). |
| <b>Blender (Principled BSDF)</b> | Vorgabe für Mischmodus (Principled BSDF). |
| <b> Corona </b> | Vorgabe für den Renderer &quot;Corona&quot;. |
| <b> CryEngine 3 </b> | Benennen und verpacken Sie Texturen, die importiert und in Cry Engine 3 verwendet werden sollen. |
| <b> Dota 2 </b> | Vorgabe für das Spiel Dota 2 (kann mit der zugehörigen Vorlage verwendet werden). |
| <b> Keyshot </b> | Vorgabe für den Renderer &quot;Keyshot&quot;. |
| <b>Keyshot 9+</b> | Voreinstellung für den Renderer &quot;Keyshot&quot; ab Version 9. |
| <b> Linsenstudio </b> | Vorgabe für Lens Studio (zum Erstellen von Elementen für Snapchat). |
| <b>Maxwell (Metallische Raueit)</b> | Vorgabe für den Maxwell-Renderer mit dem Workflow &quot;Metallische Raueit&quot;. |
| <b>Maxwell (Specular Glossiness)</b> | Vorgabe für den Maxwell-Renderer mit dem Specular-Glossiness-Workflow. |
| <b> Meshzuordnungen </b> | Exportieren Sie die Slots der Maschen-Map eines Texturensatzes einzeln (exportiert in der gleichen Auflösung wie für den Texturensatz). |
| <b>Nicht-PBR-Specular-Glanzgrad</b> | Benennen und exportieren Sie Texturen für einen Nicht-PBR-Workflow für den Specular-Glanz. |
| <b> Metallische Raueit (PBR)</b> | Benennen und exportieren Sie Texturen, die für einen regulären PBR-Workflow mit Metallic-/Raueit erforderlich sind. |
| <b> Metallische Raueit von PBR (Ordner oder PSD-Gruppen) </b> | Ähnlich wie PBR MetalRough, jedoch wird ein zusätzlicher Ordner erstellt. Diese Vorgabe eignet sich hauptsächlich für die Verwendung mit dem PSD-Dateiformat. |
| <b> PBR Specular-Glossarität</b> | Benennen und exportieren Sie Texturen, die für einen regulären Specular-/Glossiness-PBR-Workflow erforderlich sind. (Die Texturen werden aus dem BaseColor-/Metallic-Workflow konvertiert.) |
| <b> PBR-Specular-Glanzgrad (konvertiert aus &quot;Metallische Raueit&quot;</b> | Konvertieren Sie die Kanäle &quot;Grundfarbe&quot;, &quot;Metallisch&quot; und &quot;Raueit&quot; so, dass sie mit dem Arbeitsablauf &quot;Specular/Glistigkeit&quot; kompatibel sind. |
| <b> Redshift </b> | Vorgabe für den Renderer &quot;Redshift&quot;. |
| <b>Renderman (pxrDisney)</b> | Vorgabe für Renderman mithilfe von Metallic- und Rougness-Maps. |
| <b>Renderman (pxrSurface)</b> | Vorgabe für Renderman mit Diffuse- und Specular-Maps. |
| <b>Roblox (MaterialVariant)</b> | Vorgabe für Roblox mit Albedo ohne Alpha-Unterstützung. |
| <b>Roblox (SurfaceAppearance)</b> | Vorgabe für Roblox mithilfe der Farbzuordnung mit Alphakanal. |
| <b> 3D </b> schattieren | Vorgabe für &quot;3D schattieren&quot; |
| <b>Spark AR Studio</b> | Vorgabe für Spark AR Studio. |
| <b>Unity HD-Renderpipeline (Metallic Standard)</b> | Voreinstellung für die HD-Renderpipeline von Unity mithilfe von Metallic- und Glossiness Maps. |
| <b>Unity HD-Renderpipeline (Specular)</b> | Vorgabe für die HD-Renderpipeline von Unity mit hinzugefügter Specular-Map. |
| <b>Universelle Unity-Rendering-Pipeline (Metallic Standard)</b> | Vorgabe für die universelle Renderpipeline von Unity mithilfe von Metallic- und Smoothness Maps. |
| <b>Universelle Unity-Render-Pipeline (Specular)</b> | Vorgabe für die Universal-Render-Pipeline von Unity mit Specular- und Smoothness-Maps. |
| <b> Unreale Engine (verpackt) </b> | Benennen und verpacken Sie Texturen, die in der Unreal Engine mit möglichst wenig Speicher verwendet werden sollen. |
| <b>Unreal Engine SSS (verpackt)</b> | Benennen und verpacken Sie Texturen, die in der Unreal Engine mit dem niedrigstmöglichen Speicherbedarf verwendet werden sollen, und ersetzen Sie die Deckkraftmap durch Untergrundstreuung. |
| <b> Nächste Variation (metallische Raueit)</b> | Voreinstellung für den Vray-Renderer mit PBR-Arbeitsablauf. |
| <b>Nächste Variation (Specular-Glossarität)</b> | Vorgabe für den Vray-Renderer mit Nicht-PBR-Arbeitsablauf. |
| <b> Vray UDIM Legacy (Metallische Raueit)</b> | Vorgabe für den Vray-Renderer (UDIM-Benennungskonvention). |
